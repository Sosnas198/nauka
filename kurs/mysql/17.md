**Etap 59: Założenia projektu galerii**

Projekt polega na stworzeniu zestawu miniaturek, które reagują na kursor:

1. **Najechanie myszką:** Zdjęcie kolorowe zmienia się w czarno-białe (szare).
2. **Zjechanie myszką:** Zdjęcie wraca do pierwotnego, kolorowego wyglądu.
3. **Kliknięcie:** Wybrana miniaturka wyświetla się w dużym formacie w głównym panelu obok.

**Przygotowanie plików:** W folderze projektu musisz mieć zdjęcia w dwóch wersjach (np. **`pies1.jpg`** i **`pies1_szary.jpg`**) oraz duży obrazek oznaczony jako główny.

**Etap 60: Funkcja najechania (\*\***`mouseover`\***\*)**

Zamiast pisać osobną funkcję dla każdego obrazka, autor filmu tworzy jedną uniwersalną funkcję **najechanie**, która przyjmuje parametry.

- **Pobieranie elementów:** Najpierw pobierasz miniaturki po ID (np. **`pies1`**, **`pies2`**).
- **Definicja funkcji:**

```
function najechanie(miniatura, zrodlo) {
    miniatura.src = zrodlo;
}

```

- **Przekazywanie argumentów:** Aby funkcja wiedziała, który obrazek ma zmienić, używamy **funkcji anonimowej** wewnątrz **`addEventListener`**. Przekazujemy w niej obiekt obrazka i ścieżkę do szarej wersji: **`pies1.addEventListener("mouseover", function() { najechanie(pies1, "pies1_szary.jpg"); });`**.

**Etap 61: Funkcja odjechania (\*\***`mouseout`\***\*)**

Działa ona identycznie jak poprzednia, ale przywraca kolorowe zdjęcie.

- **Zdarzenie mouseout:** Wywołuje się, gdy kursor opuszcza obszar miniaturki.
- **Logika:** W funkcji anonimowej ponownie wskazujemy ten sam obiekt obrazka, ale jako źródło podajemy plik kolorowy: **`pies1.addEventListener("mouseout", function() { najechanie(pies1, "pies1.jpg"); });`**.

**Etap 62: Obsługa kliknięcia i duży obrazek**

To najważniejszy moment – musimy sprawić, by po kliknięciu duży obrazek (np. o ID **`pies_glowny`**) zmienił swoje źródło na to, które właśnie wybrał użytkownik.

1. **Pobranie głównego elementu:** **`var piesGlowny = document.getElementById("pies_glowny");`**.
2. **Funkcja klikniety:** Musi ona przyjąć aż trzy argumenty: miniaturkę (którą chcemy np. ustawić jako kolorową po kliku), ścieżkę do zdjęcia oraz **obiekt głównego zdjęcia**.
3. **Działanie:**

```
function klikniety(miniatura, zrodlo, glowny) {
    miniatura.src = zrodlo; // Miniaturka staje się kolorowa
    glowny.src = zrodlo;    // Duży obrazek zmienia się na wybrany
}

```

1. **Wywołanie:** Po kliknięciu (**`"click"`**) przesyłamy odpowiednie dane do funkcji, co powoduje natychmiastową podmianę dużego zdjęcia na stronie.

**Etap 63: Podsumowanie kursu i rady na egzamin**

Autor filmu podkreśla, że JavaScript jest **jednym z najtrudniejszych i najbardziej złożonych elementów** egzaminu INF.03, znacznie trudniejszym niż PHP czy SQL. Aby go zdać:

- Pamiętaj o pobieraniu właściwych obiektów (jeśli pobierzesz Diva zamiast obrazka, atrybut **`.src`** nie zadziała).
- Zawsze używaj słowa kluczowego **`var`** przy tworzeniu zmiennych, by kontrolować ich zasięg.
- **Ćwicz wielokrotnie:** Jeśli nie rozumiesz funkcji anonimowych lub obiektów, obejrzyj dany fragment jeszcze raz i przepisz kod samodzielnie.
