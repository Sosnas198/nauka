**Etap 26: Dodawanie danych do tabeli (\*\***`INSERT INTO`\***\*)**

Sama tabela bez danych jest jak pusty regał. Aby włożyć do niej informacje, używamy polecenia **INSERT INTO**.

1. **Podstawowa składnia:** Musimy wskazać nazwę tabeli, nazwy kolumn, które chcemy uzupełnić, oraz konkretne wartości.
   - _Przykład:_ **`INSERT INTO osoba (imie, nazwisko) VALUES ('Jan', 'Kowalski');`**.

2. **Ważne zasady:**
   - Kolejność wartości musi być dokładnie taka sama jak kolejność wymienionych kolumn.
   - Teksty (stringi) zawsze piszemy w apostrofach.

3. **Dodawanie wielu osób naraz:** Nie musisz pisać osobnej instrukcji dla każdego wiersza. Możesz wymienić zestawy danych po przecinku.
   - _Przykład:_ **`VALUES ('Jan', 'Kowalski'), ('Marek', 'Nowak'), ('Anna', 'Lis');`**.

4. **Średnik:** Pamiętaj, że dopiero średnik kończy całe zadanie dla komputera, a białe znaki czy entery w edytorze są przez serwer ignorowane.

**Etap 27: Dlaczego unikatowość jest ważna? (Problem duplikatów)**

Jeśli stworzysz tabelę bez specjalnych zabezpieczeń, możesz do niej wpisać tę samą osobę wielokrotnie.

- **Problem:** Jeśli w bazie będziesz mieć dwóch „Janów Kowalskich” z tym samym identyfikatorem (ID), komputer uzna ich za tę samą osobę.
- **Zagrożenie:** Gdyby jeden z nich chciał usunąć konto, a Ty wydałbyś polecenie „usuń osobę o ID 1”, obaj straciliby dostęp do swoich danych.
- **Rozwiązanie:** Musimy dbać o to, by każda krotka (wiersz) miała swój własny, niepowtarzalny numer, który ją zidentyfikuje.

**Etap 28: Poprawianie i usuwanie danych (\*\***`UPDATE`\*\* **i** **`DELETE`\*\***)\*\*

Dane w bazie często się zmieniają (np. ktoś bierze ślub i zmienia nazwisko albo usuwa konto).

1. **UPDATE – Zmiana danych:**
   - Służy do aktualizacji istniejących już informacji.
   - _Przykład:_ **`UPDATE osoba SET nazwisko = 'Nowak' WHERE id = 2;`**.
   - **Uwaga!** Jeśli zapomnisz o słowie **`WHERE`**, komputer zmieni nazwisko na „Nowak” wszystkim ludziom w całej bazie!.

2. **DELETE – Usuwanie wierszy:**
   - Pozwala trwale usunąć konkretny rekord.
   - _Przykład:_ **`DELETE FROM osoba WHERE id = 1;`**.
   - Tutaj również klauzula **`WHERE`** jest kluczowa – bez niej wyczyścisz całą tabelę do zera.

**Etap 29: Usuwanie całej tabeli (\*\***`DROP TABLE`\***\*)**

Jeśli uznasz, że cała tabela jest Ci już niepotrzebna (np. była tylko do testów), używasz polecenia **DROP TABLE**.

- To polecenie usuwa nie tylko dane, ale też samą konstrukcję tabeli z bazy danych.
- Jest to operacja nieodwracalna, więc zawsze warto dwa razy sprawdzić, czy usuwasz właściwą rzecz.

**Etap 30: Zaawansowane tworzenie tabel (Automatyzacja)**

W profesjonalnych bazach nie wpisujemy numerów ID ręcznie. Używamy do tego dodatkowych cech kolumn:

1. **PRIMARY KEY (Klucz podstawowy):** Gwarantuje, że dane w tej kolumnie nigdy się nie powtórzą.
2. **AUTO_INCREMENT:** To genialne narzędzie, które sprawia, że przy dodawaniu nowej osoby komputer sam nadaje jej kolejny numer (1, 2, 3...). Dzięki temu nie musisz pamiętać, jaki był ostatni numer w dzienniku.
3. **NOT NULL:** Zmusza użytkownika do wypełnienia tego pola. Jeśli ustawisz to przy imieniu, baza nie pozwoli zapisać osoby bez imienia.
4. **DEFAULT:** Pozwala ustalić wartość domyślną. Na przykład, jeśli nie podasz stanu magazynowego, baza może automatycznie wpisać tam „30”.
5. **SERIAL:** To bardzo wygodny skrót w MySQL, który jednym słowem ustawia kolumnę jako dużą liczbę całkowitą, klucz podstawowy i nadaje jej automatyczne numerowanie.
