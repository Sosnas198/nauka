# Etap 25: Zarządzanie atrybutami (`setAttribute` i `removeAttribute`)

JavaScript pozwala na dynamiczne dodawanie lub usuwanie atrybutów elementów HTML, takich jak klasy czy identyfikatory.

- **`setAttribute("atrybut", "wartość")`**: Służy do nadawania atrybutu. Przykładowo, możesz nadać elementowi klasę zdefiniowaną wcześniej w CSS: **`mojElement.setAttribute("class", "zmien-kolor");`**. Dzięki temu element natychmiast przyjmie style przypisane do tej klasy w pliku **`.css`**.
- **`removeAttribute("atrybut")`**: Pozwala usunąć dany atrybut, co sprawi, że element straci powiązane z nim właściwości (np. przestanie być czerwony, jeśli usuniemy mu klasę stylizującą).

# Etap 26: Zmiana stylów CSS bezpośrednio w JS

Możesz zmieniać wygląd elementów bez używania klas, odwołując się bezpośrednio do właściwości stylu.

- **Składnia:** Używamy zapisu **`obiekt.style.wlasciwosc = "wartosc";`**.
- **Ważna różnica w nazewnictwie:** JavaScript nie obsługuje pauz w nazwach właściwości CSS (np. **`background-color`**). Zamiast tego stosuje się zapis **camelCase** – pauza znika, a kolejny wyraz zaczyna się wielką literą.
  - **`background-color`** zamienia się w **`backgroundColor`**.
  - **`font-size`** zamienia się w **`fontSize`**.

- **Wskazówka:** Stylizacja bezpośrednio w JS nadaje style **lokalne**, które są „ważniejsze” i nadpisują style z zewnętrznych arkuszy CSS. Jeśli jednak planujesz zmieniać wiele stylów naraz, lepiej użyć wspomnianego wcześniej **`setAttribute`** i klas, aby zachować porządek w kodzie.

# Etap 27: Poruszanie się po węzłach (Node)

W drzewie DOM wszystko jest traktowane jako **węzeł (node)** – nie tylko tagi HTML, ale również tekst i białe znaki.

- **Ukryte węzły tekstowe:** Między elementami (np. między dwoma **`<div>`**) przeglądarka widzi węzły tekstowe, które są w rzeczywistości **spacjami lub znakami nowej linii** (enterami) w Twoim kodzie HTML.
- **`childNodes`**: To polecenie zwraca „pseudotablicę” wszystkich dzieci danego elementu, wliczając w to te niewidoczne znaki nowej linii. Dlatego, jeśli chcesz pobrać np. pierwszy paragraf wewnątrz Diva, musisz uważać na indeksy (często to indeks 1, bo indeks 0 to właśnie znak nowej linii).
- **Nawigacja:** Możesz używać właściwości takich jak **`parentNode`** (pobiera rodzica), **`firstChild`** (pierwsze dziecko) czy **`nextSibling`** (następny węzeł na tym samym poziomie).

# Etap 28: Tworzenie i usuwanie nowych elementów

JavaScript pozwala budować stronę „w locie” bez przeładowywania jej w przeglądarce.

1. **`document.createElement("tag")`**: Tworzy nowy element (np. **`div`** lub **`p`**), który na razie istnieje tylko w pamięci komputera.
2. **Konfiguracja:** Nowemu elementowi możesz nadać treść przez **`innerHTML`** lub zmienić jego style.
3. **`appendChild(nowyElement)`**: To kluczowy krok – dodaje on stworzony element jako „dziecko” do wybranego rodzica (np. do **`body`**), dzięki czemu staje się on widoczny na stronie.
4. **Usuwanie:** Możesz usunąć element za pomocą metody **`remove()`** (obsługiwanej przez nowsze przeglądarki) lub starszej, ale pewniejszej metody **`rodzic.removeChild(dziecko)`**.

## Ostrzeżenie dotyczące innerHTML

Częste używanie **`innerHTML += "treść"`** do dodawania elementów nie jest zalecane, ponieważ za każdym razem przeglądarka musi usuwać starą zawartość i renderować wszystko od nowa, co spowalnia stronę.
