# Etap 21: Czym jest DOM? (Wprowadzenie)

**DOM (Document Object Model)** to „obiektowy model dokumentu”. Możesz go sobie wyobrazić jako **wirtualną mapę Twojej strony**, którą przeglądarka tworzy w swojej pamięci na podstawie kodu HTML.

- **Przeglądarka jako tłumacz:** Kiedy piszesz kod HTML, przeglądarka go czyta i buduje z niego obiekt. Co ciekawe, jeśli zrobisz błąd w HTML (np. nie zamkniesz znacznika **`<div>`**), przeglądarka sama go poprawi, budując DOM, aby strona mogła się poprawnie wyświetlić.
- **Wszystko jest obiektem:** W świecie DOM każdy element strony (nagłówek, przycisk, a nawet kawałek tekstu) jest traktowany jak obiekt, którym JavaScript może manipulować.

# Etap 22: Struktura drzewa (Rodzice i dzieci)

DOM ma strukturę **drzewa**, gdzie elementy są ze sobą powiązane w hierarchii:

1. **Korzeń (Root):** Na samym szczycie jest element **`document`**.
2. **Rodzice i dzieci:** Element **`<html>`** jest „rodzicem” dla **`<head>`** i **`<body>`**. Z kolei **`<body>`** jest rodzicem dla wszystkich Twoich divów i paragrafów.
3. **Węzły (Nodes):** Wszystko na stronie jest „węzłem” – nie tylko tagi HTML, ale nawet spacje i znaki nowej linii (entery) między znacznikami są widoczne w DOM jako węzły tekstowe.

# Etap 23: Jak „złapać” element ze strony? (`getElementById`)

Aby zmienić coś na stronie, JavaScript musi najpierw „znaleźć” konkretny element. Najprostszym sposobem na egzaminie jest użycie identyfikatora **ID**.

- **W HTML:** Nadajesz elementowi unikalną nazwę, np. **`<div id="tekst1">...</div>`**.
- **W JavaScript:** Używasz instrukcji: **`var mojElement = document.getElementById("tekst1");`**.
- Dzięki temu przypisujesz cały ten fragment strony do zmiennej (pudełka) i możesz z nim robić, co chcesz.

# Etap 24: Zmiana treści na stronie (`innerHTML`)

Kiedy już „złapiesz” element do zmiennej, możesz zmienić to, co jest w jego środku, za pomocą właściwości **innerHTML**.

- **Przykład:** Jeśli masz element zapisany w zmiennej **`dom`**, piszesz: **`dom.innerHTML = "Nowa treść strony";`**.
- W momencie wykonania tej linii, stara treść znika, a na ekranie natychmiast pojawia się nowa. Strona zostaje „przerysowana” (wyrenderowana) przez przeglądarkę na nowo.

## Zadanie dla Ciebie

Spróbuj w swoim pliku HTML stworzyć paragraf z dowolnym ID (np. **`<p id="powitanie">Cześć!</p>`**). Następnie w pliku JS spróbuj go pobrać za pomocą **`getElementById`** i zmienić mu tekst używając **`innerHTML`**.

Czy rozumiesz koncepcję „drzewa” (rodziców i dzieci) oraz jak pobrać element po ID? Jeśli tak, w kolejnym kroku nauczymy się **nawigować po węzłach** (jak przejść od rodzica do konkretnego „dziecka”) oraz jak **zmieniać wygląd (style CSS)** za pomocą JavaScriptu.
