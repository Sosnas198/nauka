# Etap 7: Operatory relacyjne (porównania)

Zanim nauczymy program podejmować decyzje, musimy wiedzieć, jak zapytać go o relacje między liczbami czy tekstami. Operatory te zawsze zwracają jedną z dwóch wartości logicznych: **True** (prawda) lub **False** (fałsz).

## 1. Równość (`==` vs `===`)

- **`==` (zwykłe równa się):** Sprawdza tylko wartość. Dla JavaScriptu **`10 == "10"`** (liczba i tekst) to prawda, ponieważ ignoruje on typ danych.
- **`===` (identyczność/ścisła równość):** Sprawdza i wartość, i typ. Jest to **zalecany sposób porównywania**, bo **`10 === "10"`** zwróci fałsz (liczba to nie tekst).

## 2. Nierówność (`!=` vs `!==`)

- **`!=`:** Sprawdza, czy wartości są różne (np. czy 10 nie równa się 5).
- **`!==`:** Sprawdza, czy wartości lub typy są różne. Podobnie jak przy równości, ten zapis jest bezpieczniejszy i częściej stosowany.

## 3. Większość i mniejszość

- **`<`** (mniejsze od), **`>`** (większe od).
- **`<=`** (mniejsze bądź równe), **`>=`** (większe bądź równe).

# Etap 8: Instrukcja warunkowa `if` (Podejmowanie decyzji)

Instrukcje warunkowe pozwalają na wykonanie konkretnego fragmentu kodu tylko wtedy, gdy spełniony jest dany warunek (czyli gdy wynik porównania to **`true`**).

## Podstawowa budowa

```text
if (warunek) {
    // kod, który wykona się tylko jeśli warunek jest prawdziwy
}
```

- **Nawiasy okrągłe `()`**: Tutaj wpisujemy nasze porównanie (np. **`zakupy >= 100`**).
- **Nawiasy klamrowe `{}` (Blok kodu)**: Są niezwykle ważne. Wszystko, co zamkniesz w klamrach, traktowane jest jako jedna grupa instrukcji należąca do tego warunku. Autor filmu podkreśla, by używać ich zawsze, nawet jeśli piszesz tylko jedną linię kodu, ponieważ poprawia to czytelność i zapobiega błędom.

## Przykład z filmu (Rabat w sklepie)

Wyobraź sobie, że piszesz program dla sklepu. Jeśli klient zrobi zakupy za co najmniej 100 zł, otrzyma 10% rabatu.

```text
var zakupy = 120; // Klient wydał 120 zł [18]

if (zakupy >= 100) { // Czy 120 jest większe lub równe 100? TAK (true) [19]
    console.log("Otrzymałeś rabat 10%!"); // To się wyświetli [12]
}

console.log("Dziękujemy za zakupy."); // To wyświetli się zawsze, bo jest poza klamrami [20, 21]
```

# Etap 9: Rozszerzenia warunku – `else` oraz `else if`

Program może mieć wiele ścieżek wyboru:

1. **`else` (W przeciwnym wypadku):** Wykonuje się, gdy główny warunek **`if`** jest fałszywy.
   - _Przykład:_ Jeśli masz 100 pkt, masz wodę. **W przeciwnym wypadku (`else`)**, wyświetl „Kup więcej”.

2. **`else if` (W przeciwnym wypadku sprawdź kolejny warunek):** Pozwala tworzyć całe drabinki wyborów. Komputer sprawdza je od góry do dołu. Gdy znajdzie pierwszy prawdziwy warunek, wykonuje go i kończy sprawdzanie reszty drabinki.

## Przykład drabinki z żelkami (z filmu)

- Kupisz 3 paczki → 1 gratis.
- Kupisz 4 paczki → 2 gratis.
- Kupisz 5 lub więcej → 3 gratis.
- Kupisz mniej niż 3 → Brak promocji (**`else`**).

**Ważna uwaga:** Możesz też **zagnieżdżać** instrukcje **`if`** jedna w drugiej. Oznacza to, że drugi warunek zostanie sprawdzony tylko wtedy, gdy pierwszy był prawdziwy.
