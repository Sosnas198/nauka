# Etap 13: Metody tablic (Array Methods)

Wiesz już, jak stworzyć tablicę żelek. JavaScript daje nam gotowe „narzędzia” (metody), dzięki którym możemy tę tablicę modyfikować bez ręcznego wpisywania indeksów.

## 1. `push()` i `pop()` (Operacje na końcu)

- **`push("smak")`**: Dodaje nowy element na sam koniec tablicy. Metoda ta zwraca nową długość tablicy.
- **`pop()`**: Usuwa ostatni element z tablicy. Zwraca on nazwę elementu, który właśnie został usunięty.

## 2. `unshift()` i `shift()` (Operacje na początku)

- **`unshift("smak")`**: Dodaje element na początek tablicy, a resztę przesuwa w prawo. Zwraca nową długość tablicy.
- **`shift()`**: Usuwa pierwszy element tablicy i zwraca jego wartość.

## 3. `join()` – Zamiana tablicy w tekst

- Pozwala połączyć elementy tablicy w jeden ciąg znaków (string).
- W nawiasie podajemy, co ma oddzielać elementy, np. **`join(" - ")`** wypisze żelki oddzielone pauzami.

## 4. `concat()` – Łączenie tablic

- Służy do łączenia dwóch tablic w jedną nową.
- Ważne: sama metoda nie zmienia oryginału, więc wynik trzeba zapisać do nowej zmiennej, np. **`var nowaTablica = t1.concat(t2);`**.

## 5. `sort()` i `reverse()`

- **`sort()`**: Sortuje elementy alfabetycznie. **Uwaga:** Przy liczbach działa inaczej (traktuje je jak tekst), więc do poprawnego sortowania liczb potrzebna jest dodatkowa funkcja, o której powiemy później.
- **`reverse()`**: Odwraca kolejność elementów w tablicie.

# Etap 14: Pętle – automatyzacja zadań

Pętle pozwalają wykonywać ten sam fragment kodu wielokrotnie, dopóki spełniony jest określony warunek. To serce programowania.

## 1. Pętla `while` (Dopóki)

```text id="w5nz4p"
var i = 0; // iterator (licznik)
while (i < 5) {
    console.log("Witaj");
    i++; // zwiększamy licznik, żeby pętla nie trwała wiecznie
}
```

1. Jeśli zapomnisz o **`i++`** (inkrementacji), stworzysz **pętlę nieskończoną**, która zawiesi przeglądarkę.

## 2. Pętla `do...while`

- Różni się od **`while`** tym, że **wykona się przynajmniej raz**, nawet jeśli warunek od początku jest fałszywy. Najpierw wykonuje akcję, a dopiero potem sprawdza, czy ma ją powtórzyć.

## 3. Pętla `for` (Najczęściej używana)

- Jest najbardziej uporządkowana, bo wszystko (licznik, warunek i krok) ma w jednej linii:

```text id="f2h9q7"
for (var i = 0; i < 5; i++) {
    console.log("Obieg nr: " + i);
}
```

- **Zastosowanie z tablicami:** Pętla **`for`** idealnie nadaje się do wypisywania zawartości tablic. Zamiast pisać **`5`**, używamy **`tablica.length`**, aby pętla przeszła dokładnie przez tyle elementów, ile jest w środku.

# Etap 15: Słowa kluczowe `break` i `continue`

Wewnątrz pętli możesz sterować ich działaniem:

- **`break`**: Całkowicie przerywa działanie pętli i wychodzi z niej natychmiast.
- **`continue`**: Przerywa tylko **obecny obieg** i od razu przechodzi do sprawdzenia warunku i kolejnej iteracji. Możesz tego użyć np. żeby wypisać tylko liczby parzyste, pomijając nieparzyste.
